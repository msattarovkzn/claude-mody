# Моды Claude Code: Шкала, Передатчик, Прогресс по плану

Мод — как приборы на панели машины: двигатель тот же, а на экране появляются шкалы и подсказки. Эти три мода работают во вкладке **Code** приложения Claude для компьютера.

| Мод | Что делает |
|---|---|
| **Шкала** (`ctx`) | Под полем ввода: насколько заполнена память разговора, сколько потрачено из лимита на 5 часов (5H) и на неделю (7D), сколько минут разговор ещё «горячий» (◷) |
| **Передатчик** (`handoff`) | Когда память разговора заполнена наполовину, спрашивает «Передать?». Claude пишет себе записку, разговор очищается, работа продолжается по записке в том же окне. «Не сейчас» — спросит снова через 10% |
| **Прогресс по плану** (`plan-progress`) | Над полем ввода полоска: «План: Сайт студии ▪▪▪▫▫▫ 3/8 · дальше: страница цен». Берёт план с галочками `- [ ]` / `- [x]` из папки `plans` или `docs\plans`, который этот разговор открывал или правил. Спрятать — `/plan` |

## Как поставить

Откройте Claude → вкладка **Code** → любую свою папку и вставьте промпт:

```
Помоги мне поставить три мода для Claude Code: «Шкала» (ctx), «Передатчик» (handoff) и «Прогресс по плану» (plan-progress). Я не программист: объясняй просто, по шагам, и перед каждым действием жди моего «да».

Где лежат: github.com/msattarovkzn/claude-mody — открытый репозиторий. Скачай его архивом, регистрация на GitHub не нужна.

Как действуем:
1. Распакуй архив в папку %USERPROFILE%\.claude\mody. Эту папку потом не переносить и не удалять: моды работают оттуда.
2. Найди программу Claude Code на этом компьютере. Команды claude в PowerShell обычно нет; путь к программе записан в журнале приложения %LOCALAPPDATA%\Claude\Logs\main.log, строка «Using Claude Code binary at».
3. Подключи папку mody как источник модов и поставь три мода: ctx, handoff, plan-progress.
4. Если защита Claude не даёт поставить самому — это нормально, не обходи её. Дай мне команды по одной: я открою Пуск → PowerShell, вставлю команду, нажму Enter и пришлю, что ответило.
5. Скажи мне открыть новый разговор и проверь со мной: под полем ввода видна строка с квадратиками и процентами.
6. Объясни, как выключить любой мод, если он помешает.

Начни с плана из 5–7 шагов.
```

Для тех, кто привык к командам. `claude` — это программа Claude Code (в приложении для Windows она лежит в `%LOCALAPPDATA%\Claude-Data\…\claude-code\<версия>\…\claude.exe`, путь — в `main.log`):

```
claude plugin marketplace add "%USERPROFILE%\.claude\mody"
claude plugin install ctx@claude-mody
claude plugin install handoff@claude-mody
claude plugin install plan-progress@claude-mody
```

Выключить мод: `claude plugin disable ctx@claude-mody` (или попросить Claude).

## Что важно знать

- Моды работают с вашими правами, как любая программа. Код открыт — в нём нет выхода в интернет.
- Передатчик кладёт записки в `%USERPROFILE%\.claude\handoffs`. Claude просят не писать в них пароли и ключи, но это просьба, а не гарантия.
- Шкала считает кэш как «час с последнего ответа» — так он живёт на подписке Claude.

## Откуда

**Шкала** и **Передатчик** — моды Никиты Велса из его Telegram-канала. В Передатчике порог снижен с 60% до 50%. **Прогресс по плану** собран заново для планов с галочками.
